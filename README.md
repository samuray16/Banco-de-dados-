# Banco de Dados - Atividades 🗄️

Este repositório foi criado para armazenar e organizar scripts, exercícios e projetos práticos relacionados a **Banco de Dados**.

## 📁 Estrutura do Repositório

O projeto está organizado da seguinte forma:

*   `atividade-bd-update/` — Pasta contendo os arquivos de atividades de atualização e manipulação de dados.
*   `LICENSE` — Arquivo de licença do projeto (MIT).

## 🚀 Tecnologias Utilizadas

*   **SQL** (Structured Query Language)
*   **Git & GitHub** (Controle de versão)

## 🔧 Como Executar os Scripts

Se quiser testar os arquivos localmente em sua máquina, siga o passo a passo:

1. Clonar o repositório:
   ```bash
   git clone https://github.com/samuray16/Banco-de-dados-.git
   ```
2. Navegar até o diretório do projeto:
   ```bash
   cd Banco-de-dados-
   ```
3. Abrir os arquivos de script (`.sql` ou correspondentes) no seu Sistema Gerenciador de Banco de Dados (SGBD) de preferência (como MySQL Workbench, PostgreSQL/pgAdmin, SQL Server, etc.).
